# Experimental datasets

This directory contains the experimental triaxial datasets used in the examples presented in the accompanying manuscript.

Each dataset follows the NGC-Ucar Toolkit CSV format:

Line 1 : Dataset identifier
Line 2 : Units
Line 3 : sigma3,sigma1
Remaining lines : Experimental data

Datasets included

- Dunnville Sandstone (Tarokh et al., 2022)
- Carrara marble (Ramsey and Chester, 2004)
- Carrara marble (McCormick and Rutter, 2022)
- Berea sandstone (Bobich, 2005)

These files can be imported directly into the NGC-Ucar Toolkit or processed with the accompanying R scripts.
